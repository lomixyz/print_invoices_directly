Print Options for Invoice

✅ the user must select the desired invoice report ✅

Print Dialog

✅ The print dialog is displayed automatically once an option is selected ✅

Configurable per report

Settings > Technical > Reports > Advanced tab > Default Print Option

✅ Print Directly: the browser print dialog opens immediately.
✅ Open in a New Tab: the PDF is displayed in a new tab.
✅ Download: standard Odoo behaviour.
✅ Automatic fallback to the standard behaviour if the PDF cannot be generated.
