Print Invoice Directly

Skip the download. Click a PDF report and the browser print dialog opens right away — invoices, quotations, any qweb-pdf report.

How it works

No extra clicks, no downloaded file left behind on the user's computer.

1
Click Print on any PDF report
Invoice, quotation, delivery slip — any report that normally downloads a PDF.
2
The PDF loads in the background
Generated and fetched the same way Odoo's own download does, so multi-company and multi-language content is identical.
3
The print dialog opens instantly
No file lands in the Downloads folder — the user just picks a printer and clicks Print.

Key features

🖨️ Instant print dialog
No download step, no extra tab to close — the browser's native print dialog opens as soon as the report is ready.
⚙️ Three options, per report
Print Directly, Open in a New Tab, or Download (Odoo's own default) — set independently for every PDF report in the system.
🛡️ Safe automatic fallback
If wkhtmltopdf is missing, outdated, or the PDF can't be generated, Odoo's standard behaviour takes over and shows the real error — nothing gets stuck.
⚡ Lightweight, no dependencies
Depends only on the core "web" module — works with invoices, sales orders, or any custom qweb-pdf report.

⚙️ Configuration

  1. Install the module (depends only on web).
  2. Go to Settings > Technical > Reports and open the report you want to change (e.g. Invoices).
  3. On the Advanced tab, set Default Print Option to Print Directly, Open in a New Tab, or Download.
  4. Print Directly is the default for every PDF report as soon as the module is installed — change it per report only where you need something else.
